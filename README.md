# The Tracker Guy

Next.js (App Router) + Tailwind CSS v4.

- `npm install` then `npm run dev` (http://localhost:3000)
- `npm run build` for production
- Edit contact details, services, about text, plans and FAQ in `lib/site.ts`
- Quote form opens WhatsApp using `site.whatsapp`
- `_legacy/` holds the first static HTML draft and can be deleted
